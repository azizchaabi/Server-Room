\# Server Room Monitor



ASP.NET Core web application for managing server-room inspections, technicians, scheduling, reminders, reports, and inspection history.



\## Features



\- Server room management

\- Server-room inspections

\- Technician accounts and roles

\- Inspection scheduling

\- Inspection calendar

\- Inspection reminders

\- Email notifications

\- Inspection reports

\- PDF report generation

\- Admin dashboard and statistics



\## Technologies



\- ASP.NET Core

\- Razor Pages

\- Entity Framework Core

\- SQL Server

\- ASP.NET Core Identity

\- QuestPDF

\- MailKit
